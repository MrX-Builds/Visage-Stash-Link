# Visage Stash Link v1.1.0

The first public release of Visage Stash Link adds one small convenience to the
excellent Visage performer-results interface: right-click a performer card to
open the matching performer in local Stash, or continue to the external profile
when the performer is not present locally.

## Highlights

- Exact external-ID lookup against local Stash.
- Local performer profiles open in a new tab.
- Missing-local results retain Visage's StashDB, JavStash, FansDB, or ThePornDB
  route.
- Normal Visage selection and quick-add controls remain untouched.
- Entirely read-only: no Stash metadata mutations.
