# Changelog

## 1.1.0 — 2026-11-03

Initial public release.

- Adds a right-click context menu to Visage performer result cards.
- Resolves external stash-box IDs to matching local Stash performers.
- Opens matching local performer profiles in a new tab.
- Preserves a direct route to Visage's external performer profile when no local
  match exists or the local lookup fails.
- Recognizes StashDB, JavStash, FansDB, and ThePornDB hosts.
- Keeps Visage left-click selection and quick-add behavior unchanged.
- Uses read-only GraphQL queries and performs no Stash mutations.
